# Cinema Az

Netflix-style movie streaming frontend powered by VidAPI, ready for Cloudflare Pages.

## Features
- Site name set to **Cinema Az**
- Primary language: Azerbaijani, optional: Turkish, English, Russian
- Main pages: Home, Movies, Series, New Episodes
- Live catalog from VidAPI latest endpoints (movies/series/episodes)
- Search box for quick filtering
- Embedded playback via VidAPI player URLs
- Automatic periodic refresh for dynamic updates

## Deploy to Cloudflare Pages
- Build command: *(none)*
- Output directory: `/`

This is a static site (HTML/CSS/JS), so it can be deployed directly.
